# 規格書 (mountain_hiking_app) - MVP 離線優先版

**版本說明：** 此版本為專注於核心 GPX 功能的 MVP (最小可行性產品) 版本。所有需要網路連線、使用者登入、社群互動及雲端同步的功能都已暫時停用或修改為本機離線操作。程式碼層級保留了未來重新啟用雲端功能的架構。

---

* **最高目標：**
用戶給要去點，系統自動排出最佳路徑（最佳定義：路程最短），並套用腳程，給予精細到小時的時程安排。

* **核心價值：**
提供強大、可靠的離線 GPX 軌跡規劃與管理工具。

---

### 📊 使用情境範例
情境1：多日縱走路線規劃
1. 從**本機地圖庫**或裝置檔案選擇基本GPX
2. 刪除不需要的岔路
3. 新增每日營地航點
4. AI自動安排最佳順序
5. 匯出含營地資訊的GPX至**本機儲存**

情境2：團體登山路線調整
1. 載入標準路線
2. 刪除困難路段
3. 新增替代路徑航點
4. 調整休息點位置
5. **匯出 GPX 檔案**分享給團員

情境3：個人訓練路線
1. 上傳過去的GPX記錄
2. 刪除偏離的軌跡
3. 標記訓練檢查點
4. 設定目標時間
5. 儲存為訓練模板至**本機地圖庫**

### 📝 說明書宣告：
1.  **[MVP 版修改]** data base、server、資安、監控：此版本 App 為純離線操作，**不會主動與 Google Cloud 後端服務 (Firestore, Firebase Storage, Auth) 進行資料交換**。但保留了未來串接的程式碼架構。
2.  **應用程式開發工具說明與需求**：我使用Mac，IDE是visual studio code，開發語言是Dart，Dart的框架是Fltter，專案是用 建立本地套件 (Local Packages) / Monorepo 管理與開發加BLoC (Business Logic Component)開發。
3.  **[MVP 版修改]** **浮動選單**：整個app提供浮動選單，但選單內容已被簡化，僅保留離線核心功能。**會員管理、社群、雲端地圖庫等按鈕已被暫時隱藏**。
4.  **app畫面**：需依各裝置畫面大小自由小調整，使用時注意不要與各裝置下方的「反回、首頁、現行功能」重疊。
5.  **語系**：可以支援日文、英文、中文、印尼文、越南文、韓文 六種語言。
    1.  首次啟動引導：當使用者第一次打開 App 時，系統會主動顯示一個語言選擇介面。
    2.  語言選項：這個介面會列出 App 目前支援的所有語言。
    3.  儲存選擇：使用者選擇的語言會被儲存起來。
    4.  **[MVP 版修改]** 後續修改：使用者之後可以在 App 內的「設定」頁面隨時更改語言設定。

#### **第七頁 GPX 地圖庫 (本機版)**
*   **[MVP 版重大修改]**
*   **核心功能定義**：建立一個**完全離線**的個人化 GPX 軌跡管理中心，讓用戶能夠在**單一裝置上**有效管理、搜尋、分析 GPX 軌跡。
*   **資料儲存策略**：
    *   **儲存位置**：所有 GPX 檔案與其相關的 metadata (名稱、距離、日期等) 皆儲存於**使用者手機的應用程式內部儲存空間** (使用 SQLite 和 File System)。
    *   **優點**：可完全離線操作，反應速度快，無網路也可使用，使用者資料隱私性高。
    *   **風險**：**資料無雲端備份。若使用者解除安裝 App、清除 App 資料、或手機遺失/損壞，所有儲存的軌跡將會永久遺失。**
*   **主要功能模組**：
    *   **軌跡檔案管理**：
        *   上傳功能：從裝置的任何位置選擇 GPX 檔案，「匯入」到 App 的內部儲存空間進行管理。
        *   自動解析：匯入時，自動提取軌跡名稱、日期、距離、爬升高度等資訊存入本機資料庫。
    *   **視覺化瀏覽系統**：
        *   以列表形式顯示所有儲存在 App 內的軌跡。
        *   點擊列表項目可將該軌跡傳送至「第三頁 GPX 地圖規劃」進行編輯。
    *   **智慧搜尋與篩選**：
        *   可依據關鍵字、難度、距離、爬升高度等條件篩選本機資料庫中的軌跡。
    *   **[MVP 版移除]** 以下功能因依賴雲端與社群，在此版本中移除：
        *   ~~雲端同步~~
        *   ~~分享與社群 (分享連結、社群軌跡庫、好友系統)~~
        *   ~~個人統計儀表板 (跨裝置統計)~~
